# FeatureSetImport

**Description:** FeatureSetImport is an object representing attributes for a FeatureSet.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `analytic_sentera_id` | `ID` | The ID of the analytic that is fulfilled through this feature set. If not the result of an analytic then do not provide. |
| `annotation_file_keys` | `[FileKey!]` | File keys obtained via the create_file_upload or create_file_uploads mutations
which represent uploaded annotation files. If provided when updating a feature
set, any existing annotation files will be deleted. |
| `basemap_mosaic_sentera_id` | `ID` | The ID of the mosaic used as a basemap for this feature set. This is primarily
used for plot layouts but could be used in other applications. |
| `deliverable_key` | `DeliverableKey` | The identifier for this type of feature set when it is the deliverable on an
order. Used by Sentera, not expected to be used by customers. |
| `document_file_keys` | `[FileKey!]` | File keys obtained via the create_file_upload or create_file_uploads mutations
which represent uploaded document files.  If provided when updating a feature
set, any existing documentation files will be deleted. |
| `geometry` | `GeoJSON` | (Required on Create) The geo features to be included in the feature set. Maximum size allowed is 4 MB. |
| `name` | `String` | (Required to Create) Name of the feature set (Maximum of 255 characters). |
| `order_sentera_id` | `ID` | The ID of the analytic that is fulfilled through this feature set. If not the
result of an analytic then do not provide. Please use analytic_sentera_id instead. |
| `released` | `Boolean` | Indicator of whether or not to release the feature set. Default value is true when creating. |
| `sentera_id` | `ID` | (Required on Update) The ID of an existing feature set. This will cause the existing feature sets to be updated. |
| `type` | `FeatureSetType` | The type of this feature set (Default value is unknown). |
