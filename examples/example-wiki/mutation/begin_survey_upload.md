# begin_survey_upload

**Description:** Allow a client to tell the server it is about to start uploading images to a survey.

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `sentera_id` | `ID!` | Yes | The Sentera ID of the survey that will be getting images uploaded to it. |
| `task_sentera_id` | `ID` | No | The optional ID of the task to which the survey should be attached before the upload. |

## Return Fields

| Field | Type | Description |
|-------|------|-------------|
| `sentera_id` | `ID!` | The ID of this upload. |
