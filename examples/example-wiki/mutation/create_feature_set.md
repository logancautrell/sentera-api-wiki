# create_feature_set

**Description:** Create a feature set.

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `deliverable_key` | `DeliverableKey` | No | The identifier for this type of feature set when it is the deliverable on an
order. Used by Sentera, not expected to be used by customers. |
| `geometry` | `GeoJSON!` | Yes | The geo features to be included in the feature set. Maximum size allowed is 250 KB. |
| `name` | `String!` | Yes | The name of this feature set. Maximum length is 255 characters. |
| `owner_sentera_id` | `ID!` | Yes | The ID of the object to which this feature set is associated. |
| `owner_type` | `FeatureSetOwnerType!` | Yes | The type of object that owns this feature set. |
| `type` | `FeatureSetType!` | Yes | The type of this feature set. |
