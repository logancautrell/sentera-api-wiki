# upsert_feature_set

**Description:** Upsert (create or update) a feature set.

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `feature_set` | `FeatureSetImport!` | Yes | FeatureSetImport object to upsert. |
| `owner` | `FeatureSetOwnerInput!` | Yes | The owner to which the feature set should be upserted. |

## Return Fields

| Field | Type | Description |
|-------|------|-------------|
| `failed` | `[UpsertError!]!` | Detailed error information for UpsertItems that failed to upsert. |
| `succeeded` | `[UpsertItem!]!` | UpsertItems that have been successfully upserted. |
