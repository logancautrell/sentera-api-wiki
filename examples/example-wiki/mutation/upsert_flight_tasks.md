# upsert_flight_tasks

**Description:** Upsert (create and/or update) one or more flight tasks for an organization.

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `flight_tasks` | `[FlightTaskImport!]!` | Yes | An array of FlightTaskImport objects to upsert. The limit is 100 flight tasks. |
| `organization_sentera_id` | `ID` | No | **Deprecated:** Organization Sentera ID is now available per entry in the flight_tasks list. The ID of the organization that these flight tasks will be upserted into. |

## Return Fields

| Field | Type | Description |
|-------|------|-------------|
| `failed` | `[UpsertError!]!` | Detailed error information for UpsertItems that failed to upsert. |
| `succeeded` | `[UpsertItem!]!` | UpsertItems that have been successfully upserted. |
