# begin_tasks

**Description:** Begin one or more tasks. (Move their status from OPEN to IN_PROGRESS).

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `sentera_ids` | `[ID!]!` | Yes | An array of Task Sentera IDs to begin. The limit is 100 tasks. |

## Return Fields

| Field | Type | Description |
|-------|------|-------------|
| `failed` | `[BulkUpdateError!]!` | A list of any errors and the location in the input array. |
| `succeeded` | `[ID!]!` | A list of all the IDs on which this bulk operation succeeded. |
