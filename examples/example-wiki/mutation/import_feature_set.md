# import_feature_set

**Description:** Import a feature set.

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `analytic_sentera_id` | `ID` | No | The ID of the analytic that is fulfilled through this feature set. If not the result of an analytic then do not provide. |
| `annotation_file_keys` | `[FileKey!]` | Yes | File keys obtained via the create_file_upload or create_file_uploads mutation which represent uploaded annotation files. |
| `deliverable_key` | `DeliverableKey` | No | The identifier for this type of feature set when it is the deliverable on an
order. Used by Sentera, not expected to be used by customers. |
| `document_file_keys` | `[FileKey!]` | Yes | File keys obtained via the create_file_upload or create_file_uploads mutation which represent uploaded document files. |
| `feature_set_sentera_id` | `ID` | No | The Sentera ID of an existing feature set into which you want to import a
GeoJSON file. If not specified then a new feature set is created. |
| `file` | `String` | No | **Deprecated:** Please use geometry_file_key instead. A file key obtained via the create_file_upload or create_file_uploads
mutation which represents an uploaded GeoJSON file containing the geometry
for this feature set. |
| `file_key` | `FileKey` | No | **Deprecated:** Please use geometry_file_key instead. A file key obtained via the create_file_upload or create_file_uploads
mutation which represents an uploaded GeoJSON file containing the geometry
for this feature set. |
| `geometry_file_key` | `FileKey` | No | (Required) A file key obtained via the create_file_upload or
create_file_uploads mutation which represents an uploaded GeoJSON file
containing the geometry for this feature set. |
| `name` | `String!` | Yes | The name of this feature set. Maximum length is 255 characters. |
| `order_sentera_id` | `ID` | No | The ID of the analytic order that is fulfilled through this feature set. If
not the result of an analytic order then do not provide. Please use
analytic_sentera_id instead. |
| `owner_sentera_id` | `ID` | No | The ID of the object that owns this feature set. Required when feature_set_sentera_id is not provided. |
| `owner_type` | `FeatureSetOwnerType` | No | The type of object that owns this feature set. Required when feature_set_sentera_id is not provided. |
| `type` | `FeatureSetType!` | Yes | The type of this feature set. |

## Return Fields

| Field | Type | Description |
|-------|------|-------------|
| `status` | `AsyncProcessStatus!` | The status of the import process. |
