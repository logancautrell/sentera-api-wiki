# delete_feature_sets

**Description:** Delete one or more feature sets.

## Input Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `owner` | `FeatureSetOwnerInput!` | Yes | The owner of the feature sets to delete. |
| `sentera_ids` | `[ID!]!` | Yes | Sentera IDs of the feature sets to delete. Limited to a maximum of 1000 IDs. |
