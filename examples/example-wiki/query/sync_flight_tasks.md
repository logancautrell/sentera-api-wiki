# sync_flight_tasks

**Description:** Retrieve a list of flight tasks that have changed.

## Return Fields

| Field | Type | Description |
|-------|------|-------------|
| `deleted` | `[SyncItem!]!` | Items that have been deleted. |
| `failed` | `[SyncError!]` | A list describing errors that occurred during the syncing process. |
| `remaining_count` | `Int!` | The number of items remaining to be synced. |
| `upserted` | `[SyncItem!]!` | Items that have been inserted or updated. |
